   • APIs falhando? → Fallback automático gera dados sintéticos realistas
   • Timeout nas requisições? → Capturado e logado
   • Erro no SHAP? → Usa importância nativa do XGBoost

⭐ MODULARIDADE
   • Cada função com responsabilidade única
   • Reutilizável em outros contextos
   • Testável independentemente

⭐ INTERPRETABILIDADE
   • SHAP values explicam cada previsão
   • Gráficos mostram direção (aumenta/diminui)
   • Feature importance global vs local

⭐ VALIDAÇÃO TEMPORAL

   • Forward-chaining (treina passado, testa futuro)
   • Realista para time series

   • Docstrings completas em toda a função
   • Type hints para autocompletar no IDE
   • README com 400+ linhas
